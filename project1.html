🏠 Interior Design Portal

Project Overview

A modern full stack Interior Design Management Platform developed using Laravel, PHP, MySQL, JavaScript, Bootstrap, HTML, and CSS. The platform connects clients with interior designers and helps manage projects, bids, payments, communication, and project tracking.

Technologies Used

Project Duration

  • Responsive UI Design
  • Admin Panel Management

Database Modules

  • Users Management
  • Projects Management
  • Bids Management
  • Payments Tracking
  • Chat Messages
  • Activity Logs

Project Workflow

Clients can post interior design projects and browse designers. Designers can place bids on projects, communicate with clients, and manage ongoing work. The system includes secure payments, dashboard analytics, project tracking, and role-based access control.
